# demoMachineLearning
Ejemplos de aplicación de algoritmos de Machine Learning y Redes Neuronales Artificiales

## Instalación
1. Acceder a Google Drive usando una cuenta disponible.
2. Crear la carpeta "**demosColab**" en el raíz de la unidad (si no existe). 
3. Crear la carpeta "**demoMachineLearning**" dentro de la carpeta "demosColab" creada en el paso anterior.
4. Subir todos los archivos de este repositorio dentro de la carpeta creada en el paso anterior. 

## Uso
Para correr los ejemplos:
2. Abrir con la aplicación <**Google Colaboratory**> haciendo click derecho en el cuaderno .ipynb seleccionado.
3. Una vez abierto el entorno, mandar a ejecutar usando la opción <*Ejecutar todas*>.
